# Ambiente Front-end (Gulp + Sass)

Starter simples para desenvolvimento front-end usando **Gulp** para automação e **Sass (SCSS)** para estilização.

## ✅ O que esse projeto faz

- Compila **Sass/SCSS → CSS**
- Gera **sourcemaps** (pra debugar no DevTools sem chorar)
- **Minifica** CSS para produção
- Roda um **server local** com live reload
- Observa mudanças (watch) e recompila automaticamente

> Observação: a estrutura e tarefas podem variar conforme o `gulpfile`. Este README assume o padrão mais comum.

---

## 🧰 Requisitos

- **Node.js** (recomendado LTS)
- **npm** (vem com o Node) ou **yarn**
